# 🚀 JobCopilot

**Universal Autonomous Job Hunting & Auto-Application Platform**

Upload your resume → answer 8 baseline questions → connect your browser → JobCopilot discovers, matches, fills, and submits job applications across every major hiring platform autonomously.

When it encounters a question it doesn't know, it asks you once, learns it permanently, and never asks again.

---

## ✨ Key Features

- **🧠 Self-Learning Knowledge Vault** — Every question you answer is permanently indexed. Zero repeated questions.
- **🤖 Autonomous Multi-ATS Browser Worker** — Greenhouse, Lever, Ashby, Workday, YC, Wellfound, Naukri, Indeed.
- **🔔 Real-Time HITL Bridge** — Novel questions pause the bot, show AI-drafted answers, you approve in 1 click.
- **📊 Smart Match Scoring** — TF-IDF + bi-encoder matching with priority queue ranking.
- **🛡️ Anti-Bot Humanization** — Bézier mouse curves, randomized keystrokes, business-hours scheduling.
- **📱 Mobile Companion** — Telegram/Discord bot for HITL answers on the go.
- **📈 Analytics Dashboard** — Funnel tracking, conversion rates, response analysis.
- **🔒 Local-First & Private** — All data stays on your machine. AES-256 encrypted vault.

## 🏗️ Tech Stack
